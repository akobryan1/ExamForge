# ExamForge Training Materials
**Instructor Onboarding & Professional Development**

---

## Training Program Overview

**Duration:** 3 hours (can be split into sessions)  
**Format:** Hands-on workshop with guided exercises  
**Prerequisites:** Basic computer literacy  
**Materials Needed:** Laptop, ExamForge installed, test credentials

---

## Session 1: Introduction & Setup (45 minutes)

### **Learning Objectives:**
- Understand ExamForge capabilities
- Navigate the interface
- Configure personal settings

### **Agenda:**

#### **1. Welcome & Overview (10 min)**

**Presentation Points:**
- What is ExamForge?
  - Modern exam management platform
  - Create, publish, monitor, grade exams
  - Real-time insights and analytics
  
- Key Features:
  - Multiple question types
  - Anti-cheat measures
  - Auto-grading
  - Live monitoring
  - Advanced analytics
  
- Benefits:
  - Save time on grading
  - Reduce cheating
  - Data-driven insights
  - Professional reports

#### **2. Interface Tour (15 min)**

**Demonstration:**

1. **Launch ExamForge**
   - Show login screen
   - Explain authentication

2. **Dashboard Overview:**
   - Point out quick stats
   - Recent exams section
   - Quick actions

3. **Sidebar Navigation:**
   - Dashboard (home)
   - Structure Builder (create exams)
   - Content Builder (add questions)
   - Published Exams (manage)
   - Student Analytics (insights)
   - Settings

4. **Top Bar:**
   - User profile
   - Notifications
   - Settings gear

#### **3. Hands-On: First Login (20 min)**

**Exercise 1: Personal Setup**

Participants do:
1. Log in with provided credentials
2. Explore dashboard
3. Click each sidebar item to see different modules
4. Open Settings ? Review options
5. Set profile information (name, email)

**Check for Understanding:**
- "Where would you go to create a new exam?"
- "How do you access analytics?"
- "Where are your published exams?"

## Session 2: Creating Your First Exam (60 minutes)

### **Learning Objectives:**
- Create exam structure
- Add various question types
- Configure settings
- Publish exam

### **Agenda:**

#### **4. Exam Structure (20 min)**

**Demonstration:**

1. **Click "Structure Builder"**
2. **Fill out exam details:**
   - Title: "Sample Exam - Training"
   - Subject: "Training"
   - Description: "Practice exam for learning"
   - Passing score: 60%

3. **Add sections:**
   - Section 1: "Multiple Choice" (40 points, 20 questions)
   - Section 2: "True/False" (20 points, 10 questions)
   - Section 3: "Essay" (40 points, 4 questions)

4. **Save structure**

**Exercise 2: Create Exam Structure**

Participants do:
1. Open Structure Builder
2. Create exam: "[Your Name]'s Test Exam"
3. Add 3 sections with point allocations
4. Save
5. Verify sections appear in structure

**Tips to Share:**
- Plan structure before adding questions
- Balance question types
- Allocate time per section

#### **5. Adding Questions (40 min)**

**Demonstration:**

Show each question type:

**A. Multiple Choice:**
```
Question: What is 2 + 2?
Options:
  A) 3
  B) 4 ?
  C) 5
  D) 6
Points: 2
Explanation: Basic addition
```

**B. True/False:**
```
Statement: The Earth is flat.
Answer: False ?
Points: 1
Explanation: The Earth is a sphere (oblate spheroid)
```

**C. Essay:**
```
Prompt: Explain the significance of the water cycle.
Points: 10
Rubric:
  - Accuracy (5 pts)
  - Completeness (3 pts)
  - Clarity (2 pts)
```

**Exercise 3: Add Questions**

Participants create:
1. 5 MCQ questions in Section 1
2. 5 T/F questions in Section 2
3. 2 Essay questions in Section 3

**Provide Sample Questions:**
- MCQ: "Which planet is closest to the sun? A) Venus B) Mercury ? C) Earth D) Mars"
- T/F: "Photosynthesis occurs in animal cells. (False)"
- Essay: "Describe the process of cellular respiration."

**Check for Understanding:**
- "How do you mark the correct answer?"
- "Where do you add point values?"
- "Can you edit a question after saving?" (Yes!)

## Session 3: Publishing & Monitoring (45 minutes)

### **Learning Objectives:**
- Configure exam settings
- Publish exam
- Monitor live sessions
- Handle emergency situations

### **Agenda:**

#### **6. Exam Configuration (15 min)**

**Demonstration:**

1. **Review Tab:**
   - Check all questions complete
   - Verify point totals

2. **Schedule Configuration:**
   - Start: Tomorrow, 9:00 AM
   - End: Tomorrow, 11:00 AM
   - Duration: 90 minutes

3. **Security Settings:**
   - Enable tab switch detection
   - Enable fullscreen lock
   - Randomize questions
   - Prevent back navigation

4. **Click "Publish"**
5. **Copy exam URL**

**Exercise 4: Publish Practice Exam**

Participants do:
1. Review their exam
2. Set schedule (2 hours from now, 1 hour window)
3. Enable security settings
4. Publish
5. Copy URL to notepad

#### **7. Live Monitoring (20 min)**

**Demonstration:**

*(Use pre-staged demo with simulated students)*

1. **Navigate to Published Exams ? Live tab**
2. **Show live roster:**
   - Student names
   - Connection status
   - Progress bars
   - Time remaining
   - Flags

3. **Demonstrate controls:**
   - Broadcast message: "10 minutes remaining"
   - Extend time for individual student
   - Pause all (explain when to use)

4. **Show integrity flags:**
   - Tab switches
   - Focus loss
   - Explain severity

**Exercise 5: Monitor Demo Session**

Participants:
1. Open Live tab
2. Watch simulated students
3. Practice broadcasting message
4. Identify flagged students

#### **8. Emergency Procedures (10 min)**

**Discuss Scenarios:**

**Scenario 1: Technical Issue**
- Student loses internet
- **Action:** Extend time individually

**Scenario 2: Fire Drill**
- Building evacuation needed
- **Action:** Pause all exams immediately

**Scenario 3: Wrong Exam Published**
- Realized after students started
- **Action:** Document, communicate, consider re-take

**Scenario 4: Student Flagged**
- Multiple integrity incidents
- **Action:** Note for review, allow to continue, investigate after

## Session 4: Grading & Analytics (30 minutes)

### **Learning Objectives:**
- Review auto-graded results
- Manually grade essays
- Interpret analytics
- Export reports

### **Agenda:**

#### **9. Grading Workflow (15 min)**

**Demonstration:**

1. **Published Exams ? Closed/Grading tab**
2. **Show auto-graded questions:**
   - MCQ and T/F scored automatically
   - Instant results

3. **Manual grading:**
   - Click "Review/Grade" for essay
   - Read response
   - Use rubric
   - Assign points
   - Add feedback
   - Submit grade

4. **Bulk operations:**
   - Finalize all graded
   - Release results

**Exercise 6: Grade Sample Essays**

Participants:
1. Access grading queue
2. Grade 2 practice essays
3. Use rubric provided
4. Add constructive feedback
5. Submit grades

**Grading Tips:**
- Read entire essay first
- Reference rubric for each criterion
- Provide specific feedback
- Be consistent across students

#### **10. Analytics Review (15 min)**

**Demonstration:**

1. **Student Analytics ? Class Overview:**
   - Class average: 78.5%
   - Pass rate: 82%
   - Score distribution histogram

2. **Item Analysis:**
   - Question difficulty
   - Discrimination index
   - Quality indicators
   - **Identify:** Question with poor quality
   - **Discussion:** What to do?

3. **Student Drilldown:**
   - Select student
   - View individual performance
   - Export student report

4. **Integrity Tab:**
   - Review incidents
   - Export integrity report

**Exercise 7: Analyze Results**

Participants:
1. Open analytics for their exam
2. Identify:
   - Highest scoring question
   - Lowest scoring question
   - Class average
3. Export gradebook

**Interpretation Guide:**
- Class average < 60%: Exam too hard
- Pass rate < 70%: Review questions
- Poor quality items: Consider removal

## Trainer Notes

### **Preparation Checklist:**

- [ ] ExamForge installed on all machines
- [ ] Test credentials created for each participant
- [ ] Sample questions prepared
- [ ] Demo exam with simulated students ready
- [ ] Handouts printed
- [ ] Video projector/screen tested
- [ ] Backup plan for technical issues

### **Teaching Tips:**

1. **Go Slow:** Let participants keep up
2. **Check Understanding:** Ask questions frequently
3. **Encourage Questions:** "There are no bad questions"
4. **Real Examples:** Use your own exams as examples
5. **Hands-On Priority:** Minimize lecture, maximize practice
6. **Troubleshoot Kindly:** Technical issues will happen

### **Common Participant Questions:**

**Q: "Can students see their answers after submitting?"**
A: Only if you release results. You control when.

**Q: "What if I make a mistake in a question?"**
A: Edit before publishing. After publishing, communicate to students.

**Q: "How many students can take an exam at once?"**
A: Hundreds to thousands, depending on your infrastructure.

**Q: "Can I reuse questions across exams?"**
A: Yes! Use the Question Bank feature.

**Q: "What if internet goes out during exam?"**
A: Answers auto-save. Students reconnect and continue.
